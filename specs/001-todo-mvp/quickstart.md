# Quickstart: Todoアプリ コア機能の検証手順（001-todo-mvp）

**Date**: 2026-07-16 | **Plan**: [plan.md](./plan.md)

実装完了後（または各ストーリーのチェックポイントで）、この手順で動作を検証する。

## 前提

- Flutter 3.44.6 stable がインストール済み（`flutter --version` で確認）
- Chrome がインストール済み

## 1. セットアップと自動検証（タスク完了の必須条件）

```bash
flutter pub get      # 依存取得（shared_preferences 追加後）
flutter analyze      # 静的解析 — エラー・警告ゼロであること（憲法II）
flutter test         # 全テスト合格であること（憲法II）
```

**期待結果**: analyze はissueゼロ、test は全件パス。1件でも落ちればそのタスクは未完了。

## 2. アプリ起動

```bash
flutter run -d chrome
```

**期待結果**: Chromeが開き、空のタスク一覧（空であることが分かる表示）が出る。

## 3. 手動検証シナリオ（specの受け入れシナリオ準拠）

各ストーリーの詳細な Given/When/Then は [spec.md](./spec.md) を正とする。以下はその実行手順。

### US1: 基本のタスク管理（P1 / MVP）

1. 「牛乳を買う」と入力して追加 → 一覧に未完了として表示される
2. さらに2件追加し、1件目の完了チェックを付ける → 打ち消し表示等で完了と分かる
3. チェックを外す → 未完了表示に戻る
4. 1件削除 → 一覧から消える
5. **ブラウザをリロード** → 直前と同じ一覧（件数・完了状態）が復元される
6. 空・空白のみで追加 → 追加されない

### US2: フィルタ

1. 完了2件・未完了3件の状態を作る
2. 「未完了」→3件のみ、「完了済み」→2件のみ、「すべて」→5件表示
3. 「未完了」表示中に1件完了にする → その場で一覧から消える

### US3: タスク名の編集

1. 既存タスクの名前を編集して確定 → 表示が変わり、完了状態はそのまま
2. 空文字で確定を試みる → 元の名前が維持される
3. リロード → 編集後の名前が残っている

### US4: 期限

1. タスクに期限（明日）を設定 → 一覧に期限日が表示される
2. 期限を昨日に変更 → 期限切れの強調表示になる
3. そのタスクを完了にする → 期限切れ強調が消える
4. 期限を解除 → 期限表示が消える

## 4. データ破損時の回復（FR-011）

1. Chrome DevTools → Application → Local Storage で当該オリジンのキー
   `todo_app.tasks`（shared_preferencesのプレフィックス付き、実キーは `flutter.todo_app.tasks`）
   の値を `{broken json` に書き換える
2. リロード → アプリはクラッシュせず、空の一覧で起動する
